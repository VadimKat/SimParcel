The first release of SimParcel: drag and drop for the iOS Simulator, back after Xcode 27's Device Hub stopped accepting dropped files.

- Photos and videos go to Photos. A still image and a video with the same name import as one Live Photo.
- Contacts (.vcf), simulator builds (.app) and push payloads (.apns) are added, installed and delivered.
- Web links and deep links open in the simulator. Drag them from a browser or use File → Add Link.
- Any other file is copied to Files → On My iPhone.
- Send to one simulator, or to all running simulators at once. A simulator that isn't running starts automatically.
- Updates arrive automatically through Sparkle.
